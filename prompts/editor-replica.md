# 提示词：手绘剪辑器里的小方块（30 秒 1:1 复刻）

把下面整段复制给 AI 编程助手（WorkBuddy、Claude Code、Codex 等）。`【】` 里的内容可以换成你自己的。
成片参考：`replica/renders/editor-replica.mp4`，实现参考：`replica/index.html`。

---

先安装 hyperframes 技能（`npx skills add heygen-com/hyperframes`），然后用 HyperFrames（`hyperframes@0.8.216`，HTML + GSAP 渲染视频）做一条 30 秒、1920×1080、30fps 的静音短片：
一只橙色方块小怪物在手绘风格的视频剪辑器里自己剪片。全部画面用代码画，不用任何图片素材。

## 技术约束

- `npx hyperframes init` 建工程。`index.html` 里放一个全屏 `<canvas>`，用一个 `render(t)` 纯函数画整帧。
- 注册一个 paused 的 GSAP timeline：`tl.to(state, { t: 30, duration: 30, ease: "none", onUpdate: () => render(state.t) })`，挂到 `window.__timelines["main"]`。
- 只用确定性逻辑：禁止 `Date.now()` 和 `Math.random()`。噪点、纸纹、彩纸都用 `Math.sin` 哈希生成。
- 字体放 `assets/fonts/` 并写 `@font-face`：界面字用 Patrick Hand，贴纸大字用 Luckiest Guy，片尾手写用 Caveat Brush（都是开源字体）。
- 手绘感：圆角矩形沿边采样点，加平滑噪声抖动 ±1px，描边 3px 深棕 `#2b2118`；最后整屏叠一层预生成的纸纹噪点和淡暗角。
- 镜头：整个界面画在 1920×1080 的"世界坐标"里，每帧按关键帧插值 `(cx, cy, zoom)` 做推拉平移，缩放在对数空间插值，全部 ease-in-out。
- 不要音频，时间轴上画一条音乐轨波形即可。

## 配色和界面（世界坐标，单位 px）

- 背景米白 `#ede7d4`，窗口 `#f9f4ea`，面板 `#fbf8f1`，时间轴底 `#fefdf6`。
- 顶栏（y 15–90）：剪刀图标 + 文件名 `【opus_edit_FINAL_final(2).mp4】`；中间时间码框显示真实时间 `00:00:SS:FF`；右侧 `1080p` 框和青绿 `#31a192` 的 `EXPORT` 按钮。
- 左上素材库（x 63–426，y 102–609）：标签 `Media / Transitions / Text`，选中的标签是芥末黄 `#e6b134`。
  - Media：2×3 格子，`【sunrise.mp4 / coffee.mp4 / cat.mov / dance.mp4】` 加两个 `+` 空格。
  - Transitions：Whoosh、Spin、Glitch、Zoom、Slide、Fade。
  - Text：Classic、Pop、Outline、Bubble、Retro、Neon，各写一个 `AA`。
- 正中手机竖屏预览（中心 960,354，282×498，深棕粗边框 + 刘海）。空时显示虚线框 `+ add some media`。
- 右上调节面板（x 1495–1857）：标题 `Adjust ✦`，四个滑杆 `Sparkle / Shake / Zoom punch / Speed`，右侧显示百分比，Speed 固定 `1.0x`。
- 下方时间轴（y 618–1035）：标尺从 x 142 起，每秒 106px，每 2 秒一个 `0:02` 标签。轨道头 `T / ▶ / ♪`。
  - 文字轨 y 690，视频轨 y 750–840，音乐轨 y 862–920（浅青底 + 青色波形 + `♪ 【lyria_track.wav】` 标签），节拍标记行 y 972。
  - 红色播放头 `#e5484d`，顶部是五边形小旗。
- 四种素材画面（缩略图、片段、手机共用同一个 `scene(kind, w, h, t)` 函数）：
  - 日出：橙粉渐变天空、太阳加放射线、两座绿山、小鸟。
  - 咖啡：粉色墙、浅棕桌面、白杯子带橙色条纹、冒热气。
  - 猫：淡紫底、黑色小星星、灰猫头、黄眼睛、胡须。
  - 跳舞：浅青底、彩色圆点、方块小怪物在跳。
  - 片段边框色：日出金黄、咖啡粉红、猫紫、跳舞青绿。咖啡片段后半段是 3 格灰色 `buffering...`。

## 角色

橙色方块小怪物，颜色 `#d38959`，深棕细描边：

- 身体是 220×122 的横向方块，下面四条细腿（22×46）。
- 身体两侧各一个小短臂，抬手时短臂斜向上翻。
- 两只竖条黑眼睛，带白色高光。表情有 `^ ^`（开心）、`- -`（专注或疑惑）、蚊香眼（头晕）、单眼眨眼。
- 伸手的动作：从身体上角伸出一根很长的直条手臂，去够任何位置。
- 落地有挤压回弹，走路时四条腿交替抬起。

## 验收

1. `npm run check` 0 error。
2. `npx hyperframes snapshot --at 0.6,4.5,5.6,9.7,10.3,13.6,14.7,17.6,19.6,21.5,23.5,24.85,25.5,27.8,29.5` 逐张看图，修到满意。
3. `npm run render` 出 mp4。
4. 压缩：`ffmpeg -i in.mp4 -c:v libx264 -crf 23 -preset slow -pix_fmt yuv420p -movflags +faststart editor-replica.mp4`。
5. `ffmpeg -i editor-replica.mp4 -vf blackdetect=d=0.1 -f null -` 没有黑段；`ffprobe` 时长 30 秒。
